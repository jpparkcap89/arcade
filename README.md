# 로컬 게임센터 · 9종 재사용 패키지

`html/all-games.html`을 브라우저로 열면 배포 프로그램과 같은 게임장 안에서 걸어 다니며 9개 게임을 즐길 수 있습니다. 맵, 기계 배치, 가구, 충돌체, 조명·반사와 게임 물리는 현재 프로젝트의 구현을 그대로 사용합니다.

각 HTML은 파일 하나만 복사해도 실행됩니다. Three.js, Rapier WebAssembly와 뽑기용 8종 동물 GLB를 파일에 내장해 인터넷 연결·설치·로컬 서버가 필요하지 않습니다.

## 전체 게임장

입구에서 시작합니다. 기계 정면으로 다가가 바라보고 잠시 멈추거나 E/입장 버튼을 누르면 게임 준비 화면으로 이동합니다. 하단 게임 버튼과 상단 게임 선택은 맵 안에서 해당 기계까지 걸어가는 안내 이동입니다. 직접 이동하거나 화면을 드래그하면 안내 이동을 취소합니다.

‘게임장으로’ 또는 Esc를 누르면 입장했던 위치로 돌아옵니다. 진행 중 나가면 이번 판은 종료되며 완료 기록과 인형 보상을 저장하지 않습니다. 일시정지/계속하기, 소리, 기본/절약 화질, 전체화면을 지원합니다. 다른 탭으로 이동하면 자동 일시정지합니다.

집게 뽑기는 위·옆 보조 시점과 방향 버튼을 제공합니다. 두 뽑기는 왼쪽/오른쪽/정면 보기와 시점 드래그를 제공합니다. 타이밍 뽑기는 실제 지지 다리와 인형의 균형·낙하로 판정하고, 내려간 다리는 다음 도전에도 이어집니다. ‘새 인형으로 초기화’는 선택하려던 인형으로 다리를 초기화합니다.

이 패키지는 무료 자유 플레이용입니다. AI 문제, 교사 계정, 방 코드, 학생 접속과 중앙 순위는 포함하지 않습니다. 최고점·획득 인형 수·타이밍 뽑기 진행은 브라우저가 로컬 저장을 허용하는 경우 해당 기기에 보관합니다. WebGL 2와 WebAssembly를 지원하는 브라우저가 필요합니다.

## 소스 수정 및 재빌드

`source/src/games`에 게임 코드, `source/src/world`에 게임장, `source/src/player.ts`에 오프라인 화면·보행·실행 루프가 있습니다. `source/assets`의 인형 GLB는 빌드 시 HTML 안에 포함됩니다. 게임 이름·시간·안내·빌드 대상은 `source/games.json`에서 수정합니다.

```sh
cd source
npm install
npm run check
npm run build
```

결과는 `html/`에 생성됩니다. 소스 빌드용 패키지를 처음 설치할 때 인터넷이 필요합니다.

원본 프로젝트에서는 `npm run export:offline`으로 현재 게임·맵·모델을 동기화하고 HTML·ZIP·SHA256을 재생성할 수 있습니다. `npm run verify:offline`으로 생성물 문법, 파일 해시, 9종 목록, 모델 내장, 원본 모듈 동기화를 검사합니다. 생성물은 `exports/`에 있으며 Git에서 제외됩니다. 재생성에 필요한 템플릿과 스크립트는 `scripts/`에 보관합니다.
